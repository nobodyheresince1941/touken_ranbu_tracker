# 刀帳收集记录

这是一个简单明了的、用来记录游戏《刀剑乱舞》中刀剑男士收集进度的小网页。在这里，您可以简单地标记拥有和极化的情况、记录入手日期，按刀种和刀派·刀工筛选，并查看收集率统计和饼图。

## 使用

直接打开 `index.html` 就能用，不需要任何安装。

- 单击卡片：标记拥有 / 取消拥有
- 单击「極」：标记极化
- 单击「详情」：填写入手日期（可留空）
- 「统计」页：总收集率、极化率、按刀种和刀派·刀工的收集率，以及现有刀剑构成饼图
- 「备份」页：导出 / 导入 JSON

记录保存在当前浏览器的 localStorage 里。换设备或清除浏览器数据前，请先在「备份」页导出。

## 文件

| 路径                      | 内容                                                |
| ------------------------- | --------------------------------------------------- |
| `index.html`              | 网页本体，刀剑名单已内嵌                            |
| `data/touken_swords.json` | 刀剑名单：刀帐编号、极的编号、名字、刀种、刀派·刀工 |
| `tools/parse.py`          | 从刀帐页面数据整理出名单                            |
| `tools/merge_school.py`   | 把刀派·刀工合并进名单                               |

名单更新后，需要把 `index.html` 里 `const SWORDS = [...]` 这一段替换成新的 JSON。

## 数据来源

刀剑名单、刀帐编号和刀派·刀工分类整理自萌娘百科刀剑乱舞专题的相关页面，文字内容的使用遵循萌娘百科页面标注的授权协议。
